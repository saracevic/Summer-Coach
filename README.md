# ☀️ Summer Coach - Yaz Tatili Koçu

**AI Destekli Akıllı Eğitim Sistemi**

## 📖 Açıklama

Summer Coach, PDF veya JSON formatında ders soru bankalarını yüklemenizi ve interaktif bir şekilde çöz çözmenizi sağlayan, yapay zeka tarafından desteklenen eğitim uygulamasıdır.

### ✨ Temel Özellikleri

- 📚 **PDF & JSON Desteği**: Ders soru bankalarını kolayca yükle
- 🤖 **AI İpucu Sistemi**: Cevabı doğrudan vermek yerine, konuya odaklanmaya yardımcı olan akıllı ipuçları
- 📱 **Responsive Tasarım**: Bilgisayar, tablet ve TV'de mükemmel görüntü
- 📊 **Detaylı Sonuçlar**: Öğrenme ilerlemesini takip et
- 💡 **Konu Rehberliği**: Her soru için ilgili konuda yardım al
- 🎨 **Modern UI/UX**: Hoş ve kullanıcı dostu arayüz
